# Contributing Guidelines

Thanks for helping make this list better. A few rules to keep the bar high.

## Inclusion Criteria

A tool belongs here if it meets **all** of:

1. **It ships.** Public availability — beta is fine, vaporware is not.
2. **It's maintained.** Last meaningful commit or release within the last 12 months (or clear ongoing commercial support).
3. **It's specifically for coding workflows.** General LLM apps belong on a different list.
4. **It's distinguishable.** Not just a thin wrapper over another tool already listed.

## How to Submit

1. Fork this repo.
2. Add your entry to the appropriate section in `README.md`, keeping alphabetical order within each section (Animus is intentionally featured first as the maintainer's tool).
3. Use this format:
   ```markdown
   - [Tool Name](https://link) 🟢 🆓 — One sentence describing what it does and why it's notable.
   ```
4. Use the existing legend (🟢 open source, 💰 paid, 🆓 free tier, 🏠 self-hostable, ⭐ editor's pick).
5. Open a PR with a brief description of why the tool belongs.

## Style

- **One sentence** per tool. Be specific. Avoid marketing language ("revolutionary", "next-gen").
- Lead with what it *is*, then what makes it *notable*.
- Link to the canonical homepage or GitHub repo, not a blog post or affiliate link.
- No duplicates across sections.

## What Will Get Rejected

- Tools that haven't shipped a public version.
- Marketing landing pages with no working product.
- Self-promotion of inactive projects.
- Lists of tools (link those in "Related Lists" instead).
- Generic LLMs or AI assistants without a specific coding focus.

## Removal Policy

Tools may be removed if they:
- Become abandoned (no activity for 18+ months).
- Get acquired and shut down.
- Pivot away from coding use cases.

If you spot a stale entry, open an issue.

## Code of Conduct

Be respectful. Disagree on substance, not people. Maintainers reserve the right to close PRs and lock discussions that violate this.
